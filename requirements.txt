# Transfer & Conversion Intelligence Platform :: runtime dependencies, pinned.

# Exact versions rather than floors. A `>=` range means the image built today and
# the image built next month are different software, so a green pipeline stops
# being evidence that the artefact you are about to deploy works. Upgrades happen
# by editing this file deliberately and re-running the suites, which is the only
# point at which a dependency change is reviewable.
#
# Regenerate the pins from a known-good environment with:
#     pip freeze --exclude-editable
